ALGYM: IMPORTAR DATOS DESDE EL SISTEMA (0.3.0)

1. Instala AlGym y crea la cuenta propietaria inicial del equipo.
2. Abre el sistema en el navegador e inicia sesión con esa cuenta.
3. Ve a Administración > Importar datos.
4. Arrastra el archivo .algym o pulsa el recuadro para seleccionarlo.
5. Revisa la fecha y los conteos. Marca la confirmación y pulsa Importar datos.
6. Espera: el sistema guarda un respaldo y reinicia sus servicios. La pantalla
   se reconecta automáticamente. No cierres la pestaña durante este proceso.
7. Al ver Datos listos, entra con una cuenta de AlGym del respaldo de Hostinger.

La importación ya no se realiza desde el asistente de instalación. El navegador
es la interfaz para seleccionar, revisar, confirmar y consultar el resultado.
Solo la cuenta propietaria puede iniciar la operación. El servicio de Windows
realiza las tareas de mantenimiento sin exponer claves administrativas al sitio.

Solo acepta paquetes .algym preparados para esta versión, hasta 256 MB.
No acepta SQL, ZIP arbitrarios ni dumps crudos de Supabase. No fusiona bases
activas: el destino debe ser nuevo. Repetir el mismo respaldo no duplica datos.
Si se informa un fallo, vuelve a seleccionar el archivo después de corregir
la causa. Conserva siempre el respaldo original y los respaldos locales.

El envío de comandos al reloj permanece pausado después de la importación.
Configura y prueba el reloj posteriormente en la red del cliente.
Los cambios posteriores en Hostinger no se sincronizan automáticamente.
Antes del traslado definitivo debe prepararse un respaldo final actualizado.
